# Recipe data model

This package contains CSV templates and starter records for the VIMIAC22 recipe project

## Components

* NLP ingredient extraction and normalization
* lexical/indexed search (`search\_index.csv`)
* optional embedding search (`vector\_index.csv`)
* RDF/OWL knowledge graph mapping through `ontology\_id`

The included rows are illustrative seed data. Replace or extend them with verified data and preserve source and license metadata
